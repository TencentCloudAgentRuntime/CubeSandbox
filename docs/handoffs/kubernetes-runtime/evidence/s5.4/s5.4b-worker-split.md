## 本阶段修复的长空闲故障

Linux 的 `PR_SET_PDEATHSIG` 绑定到执行 fork 的线程，而不是父进程线程组。CubeShim 从 Tokio
runtime 线程拉起 worker 后，该线程可能因 `block_in_place` 在约 10 秒空闲后正常退休，内核会
误把它解释为 parent death 并杀死健康 worker。`94c01e21` 在认证 Hello 完成前保留
PDEATHSIG，握手完成后清除它并改用控制 seqpacket EOF 作为 CubeShim 进程生命周期 fence；
durable scanner 继续处理卡死 worker。真实进程回归覆盖“仅 fork 线程退出”和“整个父进程
SIGKILL”两条路径，本地完整 lib/integration 测试和独立 reviewer 均通过。
